# Jogo da Forca

Este programa implementa o jogo da forca, com 2 jogadores. O primeiro jogador escolhe uma palavra e o outro deve tentar
adivinhá-la letra por letra, subsituindo cada asterisco da palavra pela letra informada corretamente.

O jogador terá 6 chances de adivinhar a palavra, com cada parte do corpo da forca exibido.

## Regras do Jogo

* Cada letra na posição certa conta pontos a favor
* Cada letra errada conta pontos contra com um pedaço do corpo desenhado
* A letra correta se mostra em todos os locais da palavra onde ela aparece
* A tentativa se encerra quando a forca é desenhada completamente antes de acertar
* Ela se encerra com o acerto, com uma mensagem de sucesso.
